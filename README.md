LUMEN — Keeper of the Last Light. A 2D canvas arcade game built for make.fun's “Make the best game” bounty: you are the Keeper of the last lantern in a darkening forest. Catch fireflies to feed the light — light is both your health and your vision, so the visible world shrinks as it drains. Dodge the shadows that drain it on touch, dash with limited charges refilled each night, chain catches into combo multipliers, and survive all 5 nights until dawn. Keyboard (WASD/arrows + Space) and mouse, synthesized WebAudio sound, no libraries, no network.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
